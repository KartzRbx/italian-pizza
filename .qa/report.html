Italian Pizza 1.0.2: correções verificadas

O azul dos tipos foi substituído pelo cinza arroxeado da referência. O controle de fluxo usa verde-azulado. Todos os pares de parênteses, colchetes e chaves mantêm o roxo. A imagem enviada pelo autor é a prévia do pacote.

O que foi conferido

  • Nove testes verificaram as cores, a identidade do tema, os arquivos e a ausência dos antigos azuis.
  • 21 verificações usaram as gramáticas reais de Luau e CL++ para conferir as cores de palavras, números, comentários, funções e delimitadores.
  • 20 verificações da gramática CL++ confirmaram que await, spawn, return e thread não são confundidos com tipos. O teste foi repetido na extensão instalada.
  • As duas extensões foram instaladas pela ferramenta oficial do VS Code. Os arquivos instalados têm o mesmo conteúdo dos arquivos validados.

Limite da verificação

A aparência da janela real do editor não foi capturada. Uma janela que já estava aberta pode precisar do comando Developer: Reload Window. As setas mostram tabs; espaços aparecem como pontos. A distribuição pública é pelo GitHub Releases.
